# 业务规则与可观测性

## 金额与订单

金额统一以 `Fen`（分）为内部存储和计算单位，不使用浮点数。外部输入最多两位小数；价格、优惠、税费和订单金额需要保留快照。金额 schema 迁移必须经历准备、回填、兼容读写和收口四步。

订单支付、关闭、完成、退款与对账必须保持状态机单向演进、回调幂等和可审计。库存扣减、确认与释放同样需要幂等键和补偿路径。

## 关键指标

- 订单状态转换次数和耗时；
- 支付回调成功率、延迟、重放与签名失败；
- 生命周期任务候选数、处理数、耗时和失败；
- 依赖熔断状态、隔离并发、回退次数与请求耗时；
- 评价评分同步、Outbox 和死信积压。

仪表盘需同时按服务、接口、依赖和结果维度观察。告警应先以告警级别运行，确认阈值后再升级为值班分页。
