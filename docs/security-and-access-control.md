# 安全与访问控制

## 身份与授权

系统采用数据库驱动的 RBAC：用户、角色、权限和资源范围分离。每次后台请求必须完成身份认证、权限校验和资源范围校验；不能仅依赖前端隐藏按钮。

高风险操作需使用独立确认令牌，并记录操作者、目标、资源范围、关联 ID 和结果。应急访问令牌仅用于突破登录边界，不自动授予 RBAC 权限，最长有效期为 15 分钟。

## 账户与会话

- 登录、邮箱验证码、刷新令牌和登出都必须具备速率限制与审计。
- 冻结、恢复和解锁需要授权、审计记录与最小权限执行。
- JWT、管理员令牌、支付回调密钥和 SMTP 凭据只能由密钥管理系统提供。

## 网络与运维端点

- `/metrics`、`/livez`、`/readyz`、`/healthz` 和 pprof 只允许私有网络或受信任代理访问。
- 生产环境禁用通配符 CORS；跨主机 gRPC 使用 TLS/mTLS。
- 可信代理 IP 仅在代理网段匹配时解析，转发链从右向左剥离可信代理。
