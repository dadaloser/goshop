# 生产基线

生产环境的最低要求如下：

1. 使用审核 migration，禁止应用启动时自动改表。
2. 密钥、TLS 私钥和第三方凭据由密钥管理系统提供，不写入仓库或日志。
3. 所有服务具备健康检查、结构化日志、指标、链路追踪和可验证的优雅关闭。
4. 依赖调用有超时、隔离、熔断和降级；关键写操作具备幂等与补偿。
5. 发布采用可回滚的金丝雀策略；数据库变更优先向后兼容。
6. 变更接口、权限、支付、库存或金额前，应补充契约、边界和回归测试。

`gmicro` 已提供 HTTP 超时、就绪检查、注册前等待、注销后关闭、gRPC panic 恢复与受限优雅停止等基础能力。应用团队仍需正确配置私有运维端点、TLS、CORS、日志与密钥。
